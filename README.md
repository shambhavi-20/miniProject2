Steps:

- `git clone https://github.com/shambhavi-20/miniProject1Truthseeker.git`
- Open the clone folder in VSCode
- You are currently on the main branch. To start working you need to make your own branch. 
    -  `git branch [whatever branch name you want]`. Note that the branch at the bottom left corner is main.
    ![image](./images/terminal1.png)

    - `git checkout [whatever branch name you want]`. Note that the branch at the bottom left corner should be [whatever branch name you want].
    ![image](./images/terminal2.png)
    - You can start working now. Once you need to stop use 
        - `git add .` 
        - `git commit -m "[some small explaination of what you did]"`
        - `git push`
    - Everytime you start again, make sure the banch at the bottom left corner is your branch and not main.
